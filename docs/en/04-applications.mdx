## Operate and verify

Read [Application workflows](../application-workflows/) before creating or mutating fixtures. Use the generated URL map rather than guessing ports. A landing page, a generic 200, or a login screen cannot qualify an authenticated workflow. Review images, assets, forms, console/network failures, navigation and deep-link refresh on all required layers using [Verify](../05-verify/).

CSD browser launches establish display activity and cleanup only in the WAAP showcase; enforcement remains disabled. The application names and scenario names do not assert an exploit or mitigation outcome.
